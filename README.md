## 🔭 What I'm working on

I'm building **[Groundwork](https://github.com/Anurag012345/Groundwork)**, a multi-tenant RAG service with an embeddable website chatbot, delivered as a Docker Compose install on a client's own server.

- **Stack:** Next.js dashboard, FastAPI backend, PostgreSQL + pgvector with forced row-level security for tenant isolation.
- **Retrieval:** hybrid vector + full-text search with reciprocal-rank fusion, an optional cross-encoder reranker, and streamed answers with citations.
- **Measured, not guessed:** a 122-question golden set over 92 SEBI circulars with a CI gate on faithfulness regressions. Answer correctness went from **83.3% to 96.1%** across the pipeline changes ([full results](https://github.com/Anurag012345/Groundwork/blob/main/evals/RESULTS.md)).
